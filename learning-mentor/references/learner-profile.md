# Learner Profile

revision: 1  
updated_at: 2026-07-31

## Goal

- Grow from front-end engineering into full-stack AI application development and Agent engineering.
- Prioritize job-ready projects, then deepen large-model theory, then apply AI at current work.
- Use a 9-12 month direction, with market feedback beginning around months 4-6 rather than waiting to feel fully ready.

## Current Technical Baseline

- Front end: practical experience with Vue, TypeScript, Nuxt, Pinia, business systems, authentication, and management-system architecture.
- Python: 2/5.
- Back-end APIs and databases: 2/5.
- Docker, Linux, and deployment: 2/5.
- Mathematics for ML: 1/5.
- Machine learning and deep learning: 0/5.
- Transformer and LLM engineering: 0/5.
- Agent development: 0/5.
- Exposure: read introductory content from *Attention Is All You Need*; do not assume mastery.

## Learning Preferences

- Respond in Chinese by default; retain useful English technical terms.
- Teach intuition first, then definitions, examples, and formulas.
- Use small, correct increments and avoid skipped reasoning.
- Prefer project-led learning with theory interleaved when it becomes useful.
- Use the happy path before edge cases.
- Give honest, direct feedback without status comparisons or empty reassurance.
- Let the learner write and run code by default; use `auto:` and `verify:` for per-message authorization.

## Sustainable Pace

- Typical workday session: about 30-45 minutes.
- Typical day-off session: about 1-2 hours.
- Use sequence continuation rather than weekly quotas.
- Do not make up missed work, chase delayed tasks, or treat rest as failure.
- Keep one active learning track; use supporting or paused tracks for other interests.

## Constraints and Safety

- Do not recommend immediate resignation or a blind jump into pure algorithm roles.
- Use existing front-end experience as an advantage in AI product and engineering work.
- Avoid storing unrelated personal, financial, relationship, or sensitive information in this Skill.
- Do not store API keys, access tokens, full chat transcripts, or persistent execution permission.
