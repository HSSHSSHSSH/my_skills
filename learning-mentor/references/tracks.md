## Status Meanings

- `active`: the one current main line.
- `supporting`: a durable secondary line used only when it supports the active track.
- `paused`: an existing line intentionally not progressing.
- `planned`: accepted as a future line but not yet started.
- `completed`: its agreed completion criteria were met.

## Track Creation Rule

Do not create a track for a short question. Propose a new track only when the goal needs repeated sessions, its own milestones, or a durable task queue. Require confirmation before creating or switching a track.
